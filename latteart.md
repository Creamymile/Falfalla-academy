## 🛠 Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + shadcn/ui
- **Animation:** Framer Motion
- **State:** Zustand
- **ORM:** Prisma
- **Database:** PostgreSQL
- **Auth:** NextAuth/Auth.js
- **Payments:** Stripe
- **Uploads:** Cloudinary or UploadThing
- **Forms:** React Hook Form + Zod
- **Charts:** Recharts
